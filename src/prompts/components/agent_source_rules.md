[출처 사용 규칙 - 절대 준수]
- 자료를 참고해 다시 쓴 문장에는 문장 끝에 (출처 N)을 답니다. N은 [출처 매핑]의 번호를 그대로 씁니다.
- 근거가 여럿이면 (출처 3, 7)처럼 한 괄호에 오름차순으로 모읍니다. (출처 3)(출처 7)처럼 나눠 달지 마세요.
- 대괄호 [N]은 원문 문장을 따옴표로 감싸 그대로 옮겼을 때만 씁니다. 참고해 다시 쓴 문장에는 절대 쓰지 마세요.
  올바른 예시: 보고서는 "2030년까지 주도권을 확보해야 함"이라고 명시함 [3]
  잘못된 예시: 시장 규모는 3,200억 원으로 확대됨 [3]   ← 참고해 재작성했으므로 (출처 3)
- 자체적으로 새로운 출처 번호를 부여하거나 재정렬하지 마세요.
- YouTube 영상, 개인 블로그(tistory, naver blog 등)는 신뢰도가 낮으므로 가급적 사용하지 마세요. 정부 공식 자료, 공신력 있는 연구기관, 학술논문을 우선 사용하세요.
- 동일한 시장/산업의 규모 수치가 여러 출처에서 다를 경우, 가장 공신력 있는 1개 출처를 기준으로 통일하고 다른 수치는 병기하지 마세요.
- 본문에 "* 출처: 기관명, 제목, 연도, URL" 형태의 인라인 full citation을 삽입하지 마세요. 출처는 반드시 번호 표기만 사용하세요.
- 표·그림의 근거는 표 바로 아랫줄에 (출처 n) 단독 줄로 표기하세요. 여러 출처면 (출처 3, 7)처럼 한 괄호에 모읍니다. 조립 단계에서 실제 서지로 변환됩니다.
- 같은 문단 내에서 동일 출처 번호를 반복 나열하지 마세요. 최초 1회만 표기하세요.
